### Project Title

Campus Lost & Found System

## Problem Statement

Students frequently lose or find personal and academic belongings around a college campus. Informal communication through messaging groups may make it difficult to locate the correct owner or identify a matching lost item.

The Campus Lost & Found System provides a simple centralized command-line application for recording, searching, claiming, and tracking lost and found items within a college campus.

## Scope

The project focuses on managing lost and found item records within a campus environment.

The system supports:

- Reporting lost items
- Reporting found items
- Searching items by name, category, or location
- Viewing all reported items
- Submitting claim requests
- Marking items as returned
- Viewing reports submitted by a student
- Creating student profiles
- Viewing claim requests
- Generating summary reports
- Saving and loading item records using file handling

The application is designed for command-line use.

## Target Users

- College students
- Students who lose personal belongings
- Students who find belongings on campus
- Campus staff or administrators

## High-Level Features

- Lost item reporting
- Found item reporting
- Item search
- Item listing
- Claim request management
- Return status tracking
- Student profile management
- Personal report history
- Claim request viewing
- Summary report generation
- Local data persistence
- Input validation
